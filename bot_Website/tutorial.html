Tutorial - Adicione o Bullcord ao Seu Discord

Siga os passos abaixo para adicionar o Bullcord ao seu servidor Discord e começar a usá-lo.

Como Adicionar o Bullcord ao Seu Servidor

O Bullcord é um bot desenvolvido para fornecer informações sobre ETFs diretamente no Discord. Para adicioná-lo ao seu servidor, siga este guia simples:

  1. Obtenha o Link de Convite
    • Peça ao administrador do Bullcord o link de convite oficial. Este link é gerado usando o Discord Developer Portal.
    • O link geralmente parece com: https://discord.com/oauth2/authorize?client_id=SEU_CLIENT_ID&permissions=8&scope=bot (substitua `SEU_CLIENT_ID` pelo ID do bot).
    • Nota: Se você não tem o link, entre em contato com o suporte (veja a página de Suporte).
  2. Conecte-se ao Discord
    • Clique no link de convite fornecido. Isso abrirá uma página de autorização do Discord.
    • Faça login na sua conta do Discord, se necessário.
  3. Selecione o Servidor
    • Escolha o servidor onde deseja adicionar o Bullcord na lista suspensa.
    • Certifique-se de que você tem permissões de administrador ou gerenciador de bot no servidor.
  4. Autorize o Bot
    • Clique em "Autorizar" para conceder as permissões necessárias ao bot (ex.: enviar mensagens, criar embeds).
    • Complete o captcha, se solicitado, para verificar que você não é um robô.
  5. Configure o Bot no Servidor
    • Depois de autorizado, o Bullcord aparecerá na lista de membros do seu servidor.
    • Crie um canal de texto (ex.: #etf-info) onde o bot terá permissão para enviar mensagens.
    • Use os comandos (ex.: !preco SPY) para testar o bot.
  6. Permissões Recomendadas
    • Send Messages: Para o bot responder aos comandos.
    • Embed Links: Para exibir embeds com informações e gráficos.
    • Attach Files: Para enviar imagens de gráficos.
    • Read Message History: Para entender o contexto dos comandos.

Dicas Úteis

  • Se o bot não responder, verifique se ele está online (o status deve ser verde) e se as permissões estão corretas.
  • Use o comando !help no servidor para ver a lista de comandos disponíveis.

Problemas? Visite a página de Suporte para assistência.
